# Manual de actividades de la Carta Gantt

## Solicitud atendida

Se creó un manual complementario a la Carta Gantt para explicar, en lenguaje simple, qué debe hacer cada integrante en cada ID de actividad.

## Contenido

- 58 fichas, una por cada ID de la planificación.
- Responsable y semanas asignadas.
- Explicación directa de qué se debe hacer.
- Tres pasos mínimos de ejecución.
- Reparto concreto para Joel, Agustín y Matías en las tareas compartidas.
- Resultado que se debe guardar en el repositorio.
- Condición verificable para declarar terminada la actividad.
- Resumen personal con las 11 tareas individuales de cada integrante.
- Diccionario que traduce términos como Product Backlog, DoD, ADR, RBAC y CI.
- Rutina semanal de seguimiento y formato de actualización.

## Evidencia

- PDF: `output/pdf/Manual_de_Actividades_Carta_Gantt_SIGAA_2026.pdf`
- Extensión: 17 páginas A4 horizontales.
- Fecha: 2026-08-26.

## Verificación

El documento fue renderizado completamente y revisado visualmente. Se verificó que los 58 ID aparezcan en las fichas, que cada integrante conserve 11 tareas individuales y que las páginas tengan texto extraíble, numeración y márgenes correctos.
