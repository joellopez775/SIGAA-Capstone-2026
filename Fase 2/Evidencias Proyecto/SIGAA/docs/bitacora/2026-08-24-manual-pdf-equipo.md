# Bitácora — Manual PDF para el equipo

Fecha: 24 de agosto de 2026. Historia relacionada: PB-040.

## Solicitud del Product Owner

Generar un manual PDF con imágenes para que los integrantes puedan instalar los
requisitos, clonar SIGAA, ejecutar Docker, acceder y modificar el código, y
subir sus cambios al repositorio.

## Entregable

`output/pdf/Manual_Instalacion_Desarrollo_y_Colaboracion_SIGAA.pdf`

El documento contiene 19 páginas A4, tres ilustraciones originales, comandos
seleccionables, instrucciones diferenciadas para Windows, macOS y Linux, mapa
del código, pruebas, ramas, commits, push, Pull Requests, conflictos, seguridad,
diagnóstico y checklist de revisión.

## Verificación

- PDF generado con ReportLab.
- 19 páginas renderizadas a PNG y revisadas mediante montaje completo.
- Páginas de clonación, Pull Request y arquitectura revisadas a tamaño legible.
- Encabezados de tablas corregidos después de la primera revisión.
- Texto extraíble confirmado en todas las páginas.
- Comandos esenciales de clone, Docker, rama y push presentes.
- Sin páginas vacías, contenido cortado ni superposiciones visibles.

Las imágenes utilizadas se conservan en `entregables/manual-equipo/assets/`.
