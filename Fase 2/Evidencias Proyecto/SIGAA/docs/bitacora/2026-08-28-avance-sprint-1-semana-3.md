# Bitácora - avance Sprint 1, semana 3 simulada

Fecha simulada: 28 de agosto de 2026.

## Objetivo de la sesión

Avanzar desde la línea base documental del Sprint 0 hacia decisiones de diseño, un prototipo verificable y los artefactos de presentación de Fase 1.

## Trabajo realizado

- Se formalizaron Sprint Planning, Sprint Backlog, Scrumboard, registro Daily y burndown.
- Se resolvió técnicamente ADR-001, manteniendo pendiente la ratificación del equipo.
- Se documentaron arquitectura de contenedores, modelo ER, diccionario de datos, casos de uso y secuencia de alerta.
- Se preparó el guion de validación, sin inventar entrevistas ni resultados.
- Se desarrolló un prototipo React/Express con datos sintéticos para dashboard, estudiantes, ficha y alertas.
- Se agregaron endpoints de demostración y pruebas automatizadas de API.
- Se verificó ejecución con Docker, navegación de escritorio y respuesta móvil.
- Se actualizaron el documento institucional 1.5 y la presentación del Sprint 1.

## Decisiones y límites

- Stack técnico: React, Express y PostgreSQL; TypeScript gradual.
- Entorno reproducible: Docker Compose.
- Datos de demostración: exclusivamente sintéticos.
- Las historias PB-006 a PB-010 permanecen en revisión hasta la aceptación del Product Owner.
- La validación externa, la ratificación de roles, el feedback formativo y el ensayo no se simularon.
