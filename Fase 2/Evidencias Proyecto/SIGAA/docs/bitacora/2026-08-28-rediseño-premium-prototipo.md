# Bitácora - rediseño premium del prototipo

Fecha simulada: 28 de agosto de 2026.

## Objetivo

Reemplazar la estética inicial de dashboard genérico por una experiencia con
mayor identidad institucional, calidad percibida y coherencia con una
universidad de alto nivel.

## Dirección aprobada para revisión

- Inspiración: campus privado contemporáneo y patrones de interacción de macOS.
- Personalidad: editorial, sobria, académica y tecnológica.
- Paleta: verde biblioteca, marfil, latón, arcilla y azul mineral.
- Tipografía: Georgia para expresión institucional y fuentes nativas del sistema
  para controles y lectura funcional.

## Componentes incorporados

- Sello institucional y portada editorial.
- Sidebar flotante con iconografía, badge y perfil.
- Barra superior contextual.
- Buscador visual con atajo `⌘ K`.
- Indicadores con micrográficos de tendencia.
- Estados, badges y paneles con profundidad y contraste controlados.
