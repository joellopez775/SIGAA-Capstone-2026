# Definition of Done — SIGAA

Una historia solo puede marcarse como `Terminado` cuando cumple todos los criterios obligatorios y los criterios aplicables.

## Obligatorios

- [ ] Criterios de aceptación demostrados.
- [ ] Cambio revisado e integrado a la rama acordada.
- [ ] No contiene contraseñas, tokens ni datos personales reales.
- [ ] Pruebas relevantes ejecutadas y aprobadas.
- [ ] Evidencia enlazada a la historia y al sprint.
- [ ] Sin defectos críticos abiertos.
- [ ] Deuda o limitaciones conocidas registradas.
- [ ] Aceptación del Product Owner registrada en Sprint Review.

## Cuando corresponda

- [ ] Permisos y casos negativos de seguridad verificados.
- [ ] Manejo de errores y logging sin datos sensibles.
- [ ] Interfaz revisada en el flujo principal y resolución acordada.
- [ ] Modelo de datos, contrato API o diagrama actualizado.
- [ ] README, variables y pasos de ejecución actualizados.
- [ ] Prueba de rendimiento ejecutada contra un umbral definido.
- [ ] Manual de usuario actualizado.

## Evidencia aceptable

- Pull request o diff revisado.
- Resultado de pruebas automatizadas.
- Captura o video breve de la funcionalidad.
- Acta de validación o Sprint Review.
- Diagrama o documento versionado.
- Registro de despliegue reproducible.

## Excepciones

Una excepción debe quedar documentada con justificación, riesgo, responsable y fecha de resolución. Una excepción no permite cerrar una historia con defectos críticos ni omitir requisitos académicos obligatorios.
